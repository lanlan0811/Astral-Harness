# v0.0.1-beta

Astral 的第一个可用版本。一个能装、能跑、能改代码的桌面编码 Agent。

发布日期：2026-10-05

---

## ⚠️ 这个版本没有签名

这是 beta，正式发布前没有走代码签名和 Apple 公证。请按下面操作，否则系统会拦下来。

**macOS**

1. 下载 `.dmg`，拖进「应用程序」。
2. 首次打开会被 Gatekeeper 拦下，提示"无法验证开发者"。点**取消**，不要点"移到废纸篓"。
3. 打开 **系统设置 → 隐私与安全性**，在下方找到被阻止的提示，点**仍要打开**。
4. 之后右键点应用 → **打开** → 确认打开。

**Windows**

1. 下载 `.exe`（NSIS 安装包）。
2. SmartScreen 会弹蓝色窗口说"Windows 已保护你的电脑"。点**更多信息** → **仍要运行**。

> macOS 版本是 Universal 的，Apple Silicon 和 Intel Mac 都能装。

## 首次配置

启动后打开 **设置 → 模型服务**：

1. 选供应商（OpenAI / DeepSeek / DashScope / Ollama / 自定义）。
2. 填模型名，比如 `gpt-4o-mini`。
3. 填 API key。**它会经 AES-256-GCM 加密后存在 `~/.astral/credentials.json`**，密钥是首次启动时生成的随机文件，不在明文配置里。
4. OpenAI 兼容的服务端填 base URL，比如 `https://api.deepseek.com/v1`。

配好之后点侧栏的 **新建任务**，直接对话就行。

## 这个版本有什么

- **多轮对话，逐 token 流式输出**，对话按任务持久化，关掉应用再打开还在。
- **能真的改代码**：AgentScope 内置的 `Read` / `Write` / `Edit` / `Glob` / `Grep` / `Bash`，文件编辑和命令执行都会实时显示。
- **权限确认卡片**：跑命令、写文件之前会停下来问你，批准了才执行，拒绝了就换一个思路而不是硬来。
- **四档权限模式**，在输入框左下角切换。
- **供应商可切换**：任何 OpenAI 兼容的端点都行。
- **工作区文件树**和代码查看器。
- **终端面板**，输出按行回流。
- **中英双语界面**，跟随系统。

## 已知限制

这个版本离日常可用还有距离，下面这些是**已知没做**的，不是 bug：

- **终端不是真 PTY。** 走 `child_process`，输出按行回流。所以没有颜色、没有光标控制，`vim`、`top` 这类交互式程序用不了。
- **一次只能开一个工作区。** Agent 的 `Bash` 和文件工具按进程工作目录解析相对路径。
- **快捷键只接了一小部分。** 设置里列了 22 个，实际生效的只有 8 个（开关设置、侧栏、终端、侧面板、主题、onboarding，加上输入框的 Enter / Shift+Enter）。其余 14 个按下去没反应，包括新建任务、模型菜单、前后切换、缩放。
- **12 个设置页里只有 4 个是真的**（通用、外观、模型服务、快捷键）。浏览器、工作区搜索、子代理、MCP、技能、命令、自动化、用量统计这 8 个是占位页。
- **Git 审查面板和计划面板是空的。** 没有 git 后端，AgentScope 的 `Edit` 返回的是文本而不是结构化 diff。
- **不支持 Anthropic。** AgentScope 0.0.15 没有 `AnthropicChatModel`。要接 Anthropic 得走 OpenAI 兼容的中转，或者自己实现 `ChatModelBase`。
- **没有 MCP、skills、子代理、定时任务、记忆。**
- **没有登录和账号体系**，也不会统计用量。
- **长会话不做上下文压缩**，聊特别久会撑爆上下文预算。

## 技术说明

**为什么捆的是 Node 22。** Node 24 的官方二进制要求 macOS ≥ 13.5，会把 macOS 13.0–13.4 的用户排除在外。Node 22 是还支持 13.0 的最后一条线。

**架构。** 桌面壳是 Rust + Tauri。Agent 运行时是一个随应用分发的 Node 进程（sidecar），前端通过 Tauri 命令和事件跟它通信，sidecar 和前端之间走 stdio 的换行分隔 JSON。这个分层是必须的：AgentScope 依赖 `fs` 和 `child_process`，这些在 webview 里不存在。

**凭据加密。** 参考了 Zhiyu-Agent 的方案并改掉了它两处问题：密钥不再用 `平台+用户名+主目录` 推导（那等于没加密，知道你用户名的人就能解），改成首次启动生成的随机 32 字节文件；用户手动填的 API key 也进加密区，不再明文躺在配置文件里。
