# v0.0.1-beta

The first usable Astral. A desktop coding agent you can install, run, and that actually edits code.

Released: 2026-10-05

---

## ⚠️ This build is unsigned

This is a beta. It is not code-signed and not notarised, so both platforms will stop you. Here is the way through.

**macOS**

1. Download the `.dmg` and drag Astral into Applications.
2. Gatekeeper blocks the first launch with "cannot be verified". Click **Cancel** — do not click "Move to Trash".
3. Open **System Settings → Privacy & Security**, find the blocked message at the bottom, click **Open Anyway**.
4. Then right-click the app → **Open** → confirm.

**Windows**

1. Download the `.exe` (NSIS installer).
2. SmartScreen shows a blue "Windows protected your PC" window. Click **More info** → **Run anyway**.

> The macOS build is Universal — it runs on both Apple Silicon and Intel.

## Download

- **Windows**: `.exe` (NSIS installer)
- **macOS**: `.dmg` (Universal — Apple Silicon and Intel)

## First run

Open **Settings → Model provider**:

1. Pick a provider (OpenAI / DeepSeek / DashScope / Ollama / Custom).
2. Enter the model name, for example `gpt-4o-mini`.
3. Paste an API key. It is stored **AES-256-GCM encrypted in `~/.astral/credentials.json`**, under a random key generated on first launch — it never lands in the plaintext config.
4. For any OpenAI-compatible endpoint, set the base URL, for example `https://api.deepseek.com/v1`.

Then click **New task** in the sidebar and start talking.

## What is in this release

- **Multi-turn conversation with token-by-token streaming.** History persists per task, so it survives closing the app.
- **It genuinely edits code.** AgentScope's built-in `Read` / `Write` / `Edit` / `Glob` / `Grep` / `Bash`, with file edits and command runs shown live.
- **Permission cards.** Before a command runs or a file is written, the agent stops and asks. Approve it and it proceeds; deny it and it finds another way instead of pushing through.
- **Four permission modes**, switched from the bottom-left of the composer.
- **Switchable provider.** Any OpenAI-compatible endpoint.
- **Workspace file tree** and a code viewer.
- **Terminal panel** with output streamed back by line.
- **English and Chinese UI**, following the system language.

## Known limitations

This is still a long way from everyday use. Everything below is **known not built**, not a bug:

- **The terminal is not a real PTY.** It runs through `child_process` and streams whole lines back, so there is no colour and no cursor control. `vim`, `top`, and anything else interactive will not work.
- **One workspace at a time.** The agent's `Bash` and file tools resolve relative paths against the process working directory.
- **Most shortcuts are not wired up.** The settings page lists 22, but only 8 actually do anything (settings, sidebar, terminal, side pane, theme, onboarding, plus Enter / Shift+Enter in the composer). The other 14 are inert, including new task, the model menu, back/forward navigation, and zoom.
- **Only 4 of the 12 settings pages are real** — general, appearance, model provider, shortcuts. Browser, workspace file search, subagents, MCP, skills, commands, automations and usage are placeholders.
- **The git review and plan panes are empty.** There is no git backend, and AgentScope's `Edit` returns text rather than a structured diff.
- **Anthropic is not supported.** AgentScope 0.0.15 has no `AnthropicChatModel`. Reaching it means an OpenAI-compatible proxy, or implementing `ChatModelBase` yourself.
- **No MCP, skills, subagents, automations, or memory.**
- **No accounts or login**, and no usage tracking.
- **No context compression on long conversations**, so a very long session will exhaust the context budget.

## Implementation notes

**Why Node 22.** The official Node 24 binaries require macOS ≥ 13.5, which drops macOS 13.0–13.4. Node 22 is the last line that still supports 13.0.

**Architecture.** The desktop shell is Rust + Tauri. The agent runtime is a Node process (sidecar) shipped inside the app; the frontend talks to it over Tauri commands and events, and the sidecar speaks newline-delimited JSON over stdio. That split is not incidental — AgentScope imports `fs` and `child_process`, which do not exist in a webview.

**Credential encryption.** Follows Zhiyu-Agent's approach with two of its flaws fixed: the key is no longer derived from platform + username + home directory (which is no encryption at all, since anyone who knows your username can decrypt it) and is instead a random 32-byte file generated on first run; and a hand-typed API key now goes into the encrypted store instead of sitting in plaintext in the config.
